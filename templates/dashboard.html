  1. Create an API key in API Keys
  2. Run: curl -X POST /api/v1/order/create -H "X-Api-Key: …" -d '{"amount": 25}'
  3. Open the returned payment_url on your phone
  4. Pay via any UPI app — we'll auto-verify & fire your webhook
